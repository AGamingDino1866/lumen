# Lumen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a native Windows WPF application that renders PDF pages as selectable thumbnails, transcribes the selected pages via the Google Gemini API, and lets the user copy the result or export it to a real `.docx` — delivered as a self-contained per-user installer that requires no runtime on the target machine.

**Architecture:** Two projects split on one rule — `Lumen.Core` (`net8.0`) references no WPF and holds every piece of testable logic; `Lumen.App` (`net8.0-windows`) holds WPF, WPF-UI, and MVVM. `PdfRenderService` returns PNG **bytes**, so the only place a `BitmapSource` is created and `.Freeze()`d is the app layer. Packaging is self-contained single-file ReadyToRun for `win-x64`, wrapped by Inno Setup 6.

**Tech Stack:** .NET 8 / C# 12 / WPF · WPF-UI 4.3.0 · CommunityToolkit.Mvvm 8.4.2 · PDFtoImage 5.4.0 + bblanchon.PDFium.Win32 153.0.8009 + SkiaSharp 4.150.1 · DocumentFormat.OpenXml 3.5.1 · Markdig 1.3.2 · System.Security.Cryptography.ProtectedData 8.0.0 · xunit 2.9.3 + FluentAssertions 7.2.2 · FlaUI.UIA3 5.0.0 · Inno Setup 6.7.3

**Spec:** `docs/superpowers/specs/2026-08-21-lumen-design.md`

## Global Constraints

Every task's requirements implicitly include this section. Values are copied verbatim from the spec.

- **`Lumen.Core` must never reference WPF.** No `PresentationCore`, no `System.Windows.*`, no `BitmapSource`. Enforced by TFM (`net8.0`, not `net8.0-windows`).
- **Package versions are pinned, not floated.** WPF-UI `4.3.0`; CommunityToolkit.Mvvm `8.4.2`; PDFtoImage `5.4.0`; bblanchon.PDFium.Win32 `153.0.8009`; DocumentFormat.OpenXml `3.5.1`; Markdig `1.3.2`; System.Security.Cryptography.ProtectedData `8.0.0`; xunit `2.9.3`; FluentAssertions `7.2.2` (last Apache-2.0 release — **do not upgrade to 8.x, it is commercially licensed**); FlaUI.UIA3 `5.0.0`.
- **`PublishTrimmed` stays off.** WPF does not trim reliably.
- **Auth is the `x-goog-api-key` header.** Never a query-string parameter.
- **The API key never appears** in a log, a URL, or any user-visible error message. DPAPI-encrypted at rest.
- **PDF contents and extracted text are session-only, in memory.** Never written to disk.
- **Async all the way down.** No `.Result`, no `.Wait()`, no `async void` outside event handlers.
- **Every `BitmapSource` created off the UI thread is `.Freeze()`d before it crosses threads.**
- **Zero hardcoded `#RRGGBB` in XAML** outside `Themes/Primitives.xaml`. Enforced by a unit test.
- **No animation on keyboard-initiated actions.** Badge storyboards fire only on pointer-initiated selection.
- **Windows "Show animations" off → all durations become zero. "Transparency effects" off → no Mica.**
- **No placeholder code.** Every file complete and compiling. No `// TODO`, no elided XAML.
- **Warnings-as-errors** for Lumen's own code.

- [ ] **Step 1: Write the prompt file.** Each clause preceded by its `#!` rationale:

```
#! Establishes the role. "Transcription engine" not "assistant" — suppresses conversational framing.
You are a document transcription engine. Transcribe the page image exactly.

#! The core instruction. "Verbatim" and "reading order" together prevent both paraphrase
#! and the column-scrambling that happens on multi-column layouts.
Transcribe all visible text verbatim, in natural reading order.

#! Tables must survive as structure, not as flattened prose. Markdown tables are what the
#! Word exporter converts into real Word tables, so this clause directly feeds §12 of the spec.
Render tables as GitHub-flavoured markdown tables, preserving every row and column.

#! Heading hierarchy feeds Word Heading 1/2/3 styles, which is what makes the exported
#! document navigable in Word's navigation pane.
Preserve heading hierarchy using markdown headings (#, ##, ###) matching the visual hierarchy.

#! Without this, figures are silently dropped and the user cannot tell whether the page
#! had content the model ignored. A bracketed note is visible and greppable.
Describe figures, charts, diagrams, and photographs in a bracketed note, for example
[Figure: bar chart comparing quarterly revenue across four regions]. Never omit them.

#! The single most important guardrail. Without it the model summarises long pages.
Never summarise, never editorialise, never add commentary, never explain what you are doing.

#! Prevents hallucinated content on blank or near-blank pages, which is the most damaging
#! possible failure for a transcription tool.
If the page contains no readable text, return nothing at all. Do not invent content.

#! Suppresses the markdown code fence the model otherwise wraps long output in.
Return only the transcription. Do not wrap the output in a code fence.
```
