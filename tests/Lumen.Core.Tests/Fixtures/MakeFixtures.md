# Test fixtures

`sample.pdf` is a hand-written, 3-page PDF committed to the repository rather than generated at
test time. Committing it keeps `PdfRenderServiceTests` hermetic: the tests exercise real PDFium
rendering without depending on a generator library, a network fetch, or a document that could
drift between runs.

Page geometry is A4 (595 x 842 points). Page 1 carries a heading and a paragraph, page 2 carries
a short line, and page 3 is deliberately near-blank so the renderer is exercised against a page
with almost no ink.

It is regenerated by `MakeFixtures.ps1` in this directory if it ever needs to change.
